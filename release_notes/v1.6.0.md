# v1.6.0: 本地草稿箱、发布演练与发稿体检增强

本次更新围绕"发布前后少踩坑"补了三块能力：Web Studio 有了本地草稿箱，CLI 有了发布演练与凭据缓存，发稿体检从 5 条规则扩到 9 条。

## Web Studio：本地草稿箱

- 工具栏新增「草稿箱」浮层：多篇草稿自动保存、历史切换、新建与删除，最多保留 20 篇（超出按更新时间淘汰最旧，活动草稿不淘汰）。
- 草稿标题自动取自 frontmatter 的 `title`，其次取首个 H1，都没有则记为「未命名草稿」。
- 旧版单草稿键 `md2wx_draft` 在首次进入时一次性迁移为列表首项，原键保留不清除，回滚旧版本不会丢稿。
- 存储超限时降级为剔除内嵌图片数据后再写入；存储完全不可用时明确提示本次未持久化，编辑器内容不受影响。

## CLI：发布演练 `--dry-run`

```bash
md2wx article.md -t tech-blue -p --dry-run
```

完整走完渲染、封面解析与 Mermaid / 公式截图流程，然后打印将上报 `draft/add` 的 payload 摘要（标题、作者、摘要、封面裁切坐标、原文链接）并退出。整个过程不获取凭据、不上传素材、不推送草稿，适合发布前核对字段。

## CLI：凭据缓存与失效重试

- access_token 增加本地缓存 `~/.config/md2wx/token_cache.json`（按 app_id 隔离），未过期直接复用，减少 token 接口调用。
- 按微信 7200 秒有效期预留 5 分钟安全余量，距过期不足 5 分钟即视为失效。
- 草稿链路遇到 40001 / 42001 / 40014 时，自动刷新凭据并整链路重试一次，重试覆盖封面素材上传与 `draft/add` 两个消费环节。
- 新增 `WeChatApiError` 携带微信官方 errcode，供调用方按错误码分流。

## CLI：发稿体检 `--lint` 新增 4 条规则

- **标题层级跳跃**：H1 之后直接出现 H3 及更深层级（只提示首个跳跃点）。
- **围栏代码块缺少语言标注**：影响语法高亮与移动端阅读；纯文本块可忽略。
- **图片缺少 alt 描述文本**：微信图片折叠时无法展示语义。
- **同一图片 URL 被重复引用**：发布时会重复上传与换链，建议复用同一处引用。

规则扫描会正确跳过围栏代码块内的 `#` 注释行，避免误报。

## 渲染

- GFM 删除线现同时支持 `~text~` 与 `~~text~~` 两种写法。
- Mermaid 图表与数学公式截图失败时不再静默降级：CLI 会明示有多少处已降级为文本形态，提示发布前真机确认。
