# v1.7.0: 兼容 Obsidian 图片语法

Obsidian 插入本地图片用的是 `![[文件名]]` 写法，MD2WX 之前只认标准 Markdown 的 `![alt](路径)`，这类图片会被当成普通文本：渲染不出图，发布时也扫不到、不会上传微信 CDN。本版把这套语法接进整条图片管道。

## 渲染：识别 Obsidian 图片语法

新增一层归一化预处理，把 wiki 图片就地转成标准 Markdown，后续的内联/块级图片、CDN 换链、外链检测与 lint 全部复用原有逻辑。

- `![[架构图.png]]` → `![](架构图.png)`
- `![[架构图.png|系统架构]]` → `![系统架构](架构图.png)`（别名作为 alt）
- `![[架构图.png|320]]`、`![[架构图.png|100x200]]` → 尺寸别名丢弃（标准 Markdown 无宽度语义）
- `[[架构图.png]]`（不带 `!`）→ 同样转图片，但仅当文件名带图片扩展名；`[[某篇笔记]]` 等笔记链接保持原样
- 文件名含空格 → 空格转义为 `%20`，下游 `unquote` 还原，本地路径仍能正确解析并上传

归一化会跳过围栏代码块与行内代码，代码里写的 `![[x.png]]` 字面量不受影响；函数幂等，重复调用结果不变。

## 双端同步

CLI 与 Web Studio 使用同一套规则：`parser.py` 与 `parser.js` 各实现一份镜像函数，并接入渲染与外链检测入口。CLI 在解析正文后先归一化，让发布前的图片扫描能命中并上传微信 CDN；`--lint` 的 alt 缺失、重复图片检查也覆盖这套写法。原有标准 Markdown 图片的行为不变。
