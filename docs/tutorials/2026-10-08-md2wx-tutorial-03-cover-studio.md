# 封面不求人：双比例拼接与安全区

> **作者**：野生宝藏箱  
> **面向对象**：被公众号封面裁切折磨的内容创作者、独立开发者、设计师  
> **核心特性**：3350x1000 左右双图拼接、归一化双裁切坐标、1:1 核心安全区  

---

## 01. 永远调不对的公众号封面

在微信公众号排版流程中，最容易让人心力交瘁的环节往往不是写字，而是**配封面**。

微信官方在不同场景下的封面展示比例是截然相悖的：
- **公众号主页与订阅号信息流头条**：采用 **2.35:1** 的横版超宽画幅（推荐 900x383 或 2350x1000 高清分辨率）；
- **朋友会话卡片、微信群分享、朋友圈二次转发**：会被微信客户端自动居中裁剪为 **1:1** 的正方形小图（次条图文同样是正方形）。

这就带来了一个经典的排版矛盾：
很多作者费心设计了一张精致的 2.35:1 横版大图，在头条预览时极具视觉冲击力。但一旦转发给朋友，微信在会话框里直接居中暴力硬切，左右两侧的文字、人像或关键信息惨遭“拦腰截断”，标题变成半截，视觉效果大打折扣。

更无奈的是，**微信公众平台的底层草稿箱 API（`draft/add`）只允许一篇文章绑定一个封面素材 ID（`thumb_media_id`）**。你无法分别上传一张横版封面和一张方版封面，只能由系统在一张素材上进行裁切。

## 02. 双封面左右拼接黑科技（3350x1000）

为了从根源上化解这个矛盾，MD2WX 探索并实现了一套**单图双裁切工程方案**：将横版封面与方版封面无缝拼合成一张超宽素材图。

### 1. 拼接几何学
- 头部横图（2.35:1）：标准高分辨率为 **2350 × 1000** 像素；
- 分享方图（1:1）：标准高分辨率为 **1000 × 1000** 像素；
- 左右无缝并排合成：$2350 + 1000 = 3350$，最终生成一张 **3350 × 1000** 像素的超清合图。

```
+----------------------------------------------------+--------------------------+
|                                                    |                          |
|             2.35:1 头条横版大图                    |       1:1 分享方图       |
|                 (2350 x 1000)                      |      (1000 x 1000)       |
|                                                    |                          |
+----------------------------------------------------+--------------------------+
0                                                 0.701493                      1.0 (归一化X)
|<----------------- 70.15% ------------------------->|<-------- 29.85% -------->|
```

### 2. 归一化双裁切坐标
微信草稿箱 API 支持通过字段上报归一化裁剪参数（取值在 0 到 1 之间）。MD2WX 经过精确推导，在推送草稿时自动附加以下两个坐标字段：

- **头条 2.35:1 裁剪坐标**：`pic_crop_235_1="0_0_0.701493_1"`
  - 含义：从合图左上角 $(0, 0)$ 开始取，横向截取至 $2350 / 3350 \approx 0.701493$，纵向截取满高 $1.0$。
- **次条/分享 1:1 裁剪坐标**：`pic_crop_1_1="0.701493_0_1_1"`
  - 含义：从合图横向 $0.701493$ 处开始取，一直到最右侧 $1.0$ 结束，截取宽度正好是 $1000 / 3350 \approx 0.298507$，长宽比严格等于 $1000:1000 = 1:1$。

通过这套参数，微信服务器在处理草稿时，头条会自动精准展示左侧的 2.35:1 画面，而会话与朋友圈转发则自动对齐右侧的 1:1 画面，两者互不干扰，彻底解决排版断头。

## 03. Web 端 Cover Studio 封面工坊

对于普通用户，MD2WX Web 工作台直接内置了可视化的 **Cover Studio（封面工坊）**。

### 1. 打开封面画板
在 Web Studio 顶部工具栏切换至「封面」选项卡，界面将展示当前主题预设的 2.35:1 与 1:1 实时双视框画板。

### 2. 动态主题预设与文字排版
Cover Studio 为全部 9 套排版主题定制了同源的封面模板（例如科技蓝的网格阵列、复古报刊的排印框线、极客终端的绿光提示符）。
你只需在配置框中填入：
- 文章主标题（建议 15 字以内）；
- 文章副标题或导读；
- 作者名与发布日期。

画板会实时光栅化渲染，保证封面与文章正文具有完全一致的视觉统一感。

### 3. 一键导出与坐标复制
点击画板下方的 **「导出 3350x1000 双封面」**，浏览器会利用 Canvas 2D 引擎合成并下载超清 PNG 文件。
同时，工具栏提供了 **「复制裁剪坐标」** 按钮，方便你在手工上传时直接参考。

## 04. CLI 自动合成与草稿箱直推

在本地使用命令行时，MD2WX 的封面处理更加简单：

### 1. 纯自动模式（零手动配置）
如果你没有专门准备封面，在执行草稿箱推送时：

```bash
md2wx my_article.md --publish
```

MD2WX 会在后台自动调用内置的动态封面生成器，抓取文章的 Markdown H1 标题作为主视觉，渲染出一张匹配当前主题的 3350x1000 双比例合图，自动上传微信永久素材并上报裁剪坐标。你无需准备任何图片。

### 2. 自定义双图拼接模式
如果你已经为头条和会话各做了一张设计图：
- `assets/banner.png`（2350x1000 横图）
- `assets/square.png`（1000x1000 方图）

只需在命令行中一并传入：

```bash
md2wx my_article.md --publish \
  --cover assets/banner.png \
  --cover-square assets/square.png
```

CLI 会自动在内存中把两张图片无缝合拼为合图并提交微信后台。

## 05. 单图降级：1:1 核心安全区策略

如果手上确实只有一张 2.35:1 的单图，无法做左右合拼，该怎么办？

MD2WX 同样提供了**中心 1:1 安全区**指引方案：
在 2350x1000 的横图中，当微信按 1:1 强行居中裁切时，其截取的水平范围是：
- 水平有效区间：从横坐标的 **$28.7\%$** 到 **$71.3\%$**。

因此，单图设计的黄金法则是：
**将所有的核心文字、标题、Logo 或人物主体，严格约束在正中间宽度 42.6% 的正方形安全框以内。** 左右两侧只保留背景纹理或延伸装饰。这样即便在会话列表被粗暴居中裁切，核心信息依然完好无损。
