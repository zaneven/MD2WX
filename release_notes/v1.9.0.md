# v1.9.0: 发稿体检双端对齐

把 CLI 的发稿规范校验搬进 Web 工作台，同时补齐发布门禁、机器可读报告与几项最基础的编辑体验。

## 发稿规范校验（双端对齐）

- 规则从 9 条扩到 13 条，`code` 编号、判定顺序、级别与文案在 `md2wx/linter.py` 与 `web/src/core/lint.js` 中逐条一致，每条问题都带行号。
- 新增规则：`title-punctuation` / `digest-punctuation`（标题、摘要以句读标点收尾）、`emoji-banned`（正文与标题禁用 Emoji）、`html-unclosed`（未闭合的块级 HTML 标签，定为 error）、`link-format-invalid`（缺协议、含空白、非 http/https）、`punctuation-mixed`（中文里混用半角标点）。
- `tests/test_lint_consistency.py` 在 Node 环境下逐条比对双端问题清单，两份引擎不再有静默分叉的空间。

## CLI：发布门禁与 JSON 报告

- `-p` / `--publish` 现在默认先跑一遍校验：存在 error 级问题会在获取凭据、上传图片之前中止，不发出任何网络请求；`--no-lint` 是紧急逃生通道。
- 这是行为变更：以前发布只做提示，现在会真的拦下来。
- `--lint --format json` 输出单个 JSON 对象（含 `file`、`issues`、`summary`），可以直接 `jq` 处理，方便接进自己的发布流程。
- `--check-links` 用线程池并发对正文外链发 HEAD 请求，超时或不通降级为 `link-timeout` / `link-unreachable` 警告，仅供 CLI 使用。

## Web 工作台

- 预览区底部常驻体检栏：按 error / warn 分组列出问题，点击条目跳到编辑器对应行，预览同步滚动。
- 存在 error 级问题时阻断复制，避免把排版会崩的正文粘进微信后台。
- 半角标点提供一键修复，只改标点，不动正文其他字符。
- 状态栏常驻正文字数、预计阅读时长与图片数量。
- 新增大纲抽屉，按 H1-H6 生成层级目录，点击定位正文并同步预览视口，Esc 关闭。
- 支持把本地 `.md` 文件直接拖进编辑器打开。
