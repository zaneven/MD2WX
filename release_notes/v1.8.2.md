# v1.8.2: 工具栏换行与预览宽度修复

修复 v1.8.1 增加工具栏按钮后，编辑栏被撑宽、右侧预览窗口被挤压的问题。

## 布局修复

- 编辑区与预览区恢复等宽分配，两侧都允许收缩，不再被工具栏的最小内容宽度撑开。
- 工具栏改为按可用宽度自动换行：宽屏保持一行，窄屏显示两到三行，不再横向滚动或隐藏按钮。
- 清空按钮跟随工具栏一起换行，图片插入浮层在换行后仍能正常展开。

## 验证

- 在 1920 / 1600 / 1440 / 1280 / 1024 宽度下，编辑区与预览区宽度一致，页面没有横向溢出。
- 新增工具栏按钮功能回归通过，179 项 Python 测试与 Web 构建通过。
