# 告别复制粘贴：一键直推微信草稿箱

> **作者**：野生宝藏箱  
> **面向对象**：技术博主、独立创作者、有定期稳定发文节奏的团队  
> **核心命令**：`md2wx article.md --publish`  

---

## 01. 终结繁琐的人肉搬运

在传统的公众号发布流程中，写完一篇带有多张配图的文章后，通常要经历以下机械步骤：
1. 打开公众号后台新建草稿；
2. 逐一上传正文中的配图并调整位置；
3. 打开设计工具导出封面图并上传，小心翼翼地对齐裁切框；
4. 复制排版好的文字，粘贴到正文中；
5. 反复保存并在手机上发送预览。

这一连串操作往往要耗费十多分钟，且极容易在手动替换图片时搞错顺序。

MD2WX 提供了直接对接微信官方草稿箱 API 的闭环发布能力。配置好凭据后，只需要在终端输入：

```bash
md2wx my_article.md --publish
```

工具会在数秒内自动完成：**获取凭据 -> 本地图片全量换链为微信 CDN -> 自动生成双比例合图封面并上传素材库 -> 注入裁剪坐标与草稿正文 -> 返回微信官方临时预览链接**。

---

## 02. 第一步：获取微信公众号开发者凭据

微信公众平台官方 API 仅向公众号的开发者开放，因此你需要先在后台获取开发凭据。

### 1. 找到 AppID 与 AppSecret
1. 登录微信公众平台（mp.weixin.qq.com）；
2. 在左侧菜单栏拉到底部，进入 **「设置与开发」 -> 「基本配置」**；
3. 在开发者 ID 一栏中，复制你的 **开发者 ID (AppID)**；
4. 点击「生成」或「重置」**开发者密码 (AppSecret)**。请妥善保存该字符串，关闭弹窗后后台将不再明文显示。

### 2. 配置 IP 白名单（非常重要）
微信对于草稿箱与素材上传接口有严格的安全限制，**调用接口的机器出口 IP 必须在白名单内**。
- 在「基本配置」页面中找到「IP 白名单」，点击修改；
- 将你当前电脑或服务器的公网 IP 加入列表中。如果不确定本机公网 IP，可以在终端执行：
  ```bash
  curl ifconfig.me
  ```
  将返回的 IP 地址填入并保存即可。

---

## 03. 第二步：配置凭据探测链

为了保证凭据安全且不随代码仓库误提交，MD2WX 支持通过环境变量管理凭据。

在你的工作目录中复制配置模版：

```bash
cp .env.example .env
```

打开 `.env` 文件，填入刚才获取的凭据：

```bash
WECHAT_APP_ID=wx98c10ae878xxxxxx
WECHAT_APP_SECRET=20827782e3e1f62xxxxxx
```

### 多级凭据自动探测
为了方便多项目共用配置，MD2WX 实现了智能的多级探测链。当你运行发布命令时，程序会按以下优先级依次探测，只要找到有效凭据即刻生效：
1. **当前工作目录**下的 `.env` 文件；
2. **开发目录**下的公共配置：`~/Develop/wx-serv/.env`；
3. 当前系统的**全局环境变量**（`export WECHAT_APP_ID=...`）。

这意味着你在常用的工作区配置一次之后，在其他项目目录下无需反复复制 `.env` 文件。

## 04. 第三步：一行命令直推草稿箱

完成配置后，即可在终端对你的 Markdown 文稿执行发布：

```bash
md2wx my_article.md --publish
```

此时终端会输出连贯的执行流水线日志：

```text
[1/5] 验证微信凭据并获取 access_token... 成功 (Token 已缓存)
[2/5] 扫描正文配图并自动换链微信 CDN...
      -> 上传本地配图: assets/arch.png => https://mmbiz.qpic.cn/...
      -> 上传外部外链: https://example.com/demo.jpg => https://mmbiz.qpic.cn/...
[3/5] 准备封面图素材...
      -> 自动渲染 3350x1000 双比例拼接封面 (头条 2350x1000 + 方图 1000x1000)
      -> 上传微信永久图片素材库... 成功 (Media ID: 3kXJ8...)
[4/5] 组装草稿 Payload 并注入精确裁剪坐标:
      -> pic_crop_235_1 = "0_0_0.701493_1"
      -> pic_crop_1_1   = "0.701493_0_1_1"
[5/5] 提交微信官方草稿箱 (draft/add)... 成功！

============================================================

```

在终端输出的临时预览链接上按住 `Cmd` 键并点击，即可在浏览器中直接预览在微信客户端里的真实渲染效果。

## 05. 核心工程细节与排坑指南

在对接微信草稿箱 API 时，MD2WX 在底层处理了几个隐蔽的深坑：

### 1. 微信防静默截断保护
微信公众平台的草稿接收接口对非法字符非常敏感。如果 Markdown 文稿中包含空字节（`\x00` Null Byte）或部分未经转义的特殊控制字符，微信接口**不会报错**，而是会**静默截断文章**——导致后面的几十个段落凭空消失。
MD2WX 在提交前会对全文进行控制字符 Sanitization 清理，确保整篇文章完整入库。

### 2. 避免素材库图片重复上传（MD5 缓存）
如果文章中有 10 张图，每次修改文字后重新运行 `--publish`，是否会导致微信素材库被重复垃圾图片占满？
MD2WX 内部实现了基于图片文件 MD5 哈希的本地缓存机制。对于已经成功上传到微信 CDN 的图片，工具会自动复用已有的微信图片 URL，既加快了发布速度，又避免消耗素材库配额。

### 3. Frontmatter 自动解析
如果你的 Markdown 头部包含标准的 YAML Frontmatter，例如：

```markdown
---
title: 架构设计的权衡思考
author: 野生宝藏箱
digest: 本文梳理在现代系统架构中关于延迟与一致性的核心取舍。
---
```

MD2WX 会自动提取 `title` 作为公众号文章标题、`author` 作为作者字段、`digest` 作为群发图文摘要，并在渲染正文时将这段元数据剥离，完全贴合主流静态博客的写作习惯。
