## 阅读建议

- 如果你只想找一个**开箱即用、不需要配置环境、复制进公众号不丢样式**的工具，请直接阅读 **第 01 篇**。
- 如果你有本地写作习惯（Markdown 本地文件管理），希望在终端一行命令搞定排版，请阅读 **第 02 篇**。
- 如果你被微信公众号封面“横图被裁成方图文字断头”的问题折磨过，请看 **第 03 篇**。
- 如果你追求全自动化，想在写完 Markdown 后直接推送到微信后台生成草稿，请依次阅读 **第 04 篇** 与 **第 06 篇**。
- 如果你的团队有独特的视觉识别（VI）规范，需要定制专属排版模版，请参考 **第 05 篇**。
