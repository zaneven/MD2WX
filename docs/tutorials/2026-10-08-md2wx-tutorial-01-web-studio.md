## 01. 找一个干净、免费的排版工具怎么这么难

很多人在公众号排版上都踩过同样的坑：
- 传统的富文本排版平台功能越来越庞大，打开页面先弹三四个充值弹窗；
- 好看一点的标题样式、分割线甚至代码块，旁边都标着「VIP 专享」；
- 不少工具强制要求扫码登录、绑定手机号，甚至限制单月排版篇数和字数；
- 还有一些工具导出或复制时偷偷在文末夹带版权小尾巴，或者在手机端看时排版彻底变形。

写文章本该是一件专注于内容的事情。如果你平时习惯用 Markdown 写作，想要的无非是一个**完全免费、没有广告打扰、打开就能用、复制进微信后台绝不丢格式**的排版转换器。

MD2WX Web Studio 就是为了解决这些痛点而做的一个纯前端排版工具。它由开源项目驱动，坚持完全免费与纯净体验：

- **数据完全本地化**：没有后端数据库存储你的文章草稿，所有的 Markdown 解析、内联样式注入都在你的浏览器本地内存完成，断网也能正常排版；
- **零弹窗无广告**：界面只有纯粹的双栏编辑区与仿真视口，保持克制的设计质感。

## 02. 三分钟上手核心工作流

MD2WX 在线工作台采用直观的「左侧编辑、右侧仿真」双栏布局。

日常排版只需三步即可完成：

### 第一步：粘贴你的 Markdown 文稿
将你在本地编辑器（如 Obsidian、Typora、Notion 或 VS Code）写好的 Markdown 文稿直接粘贴到左侧编辑区。右侧的移动端仿真视口会在毫秒级内完成实时渲染。

### 第二步：挑选与微调视觉主题
点击顶部工具栏的主题菜单。MD2WX 并不是简单地换个强调色，而是整套视觉骨架的切换：
- **tech-blue（现代科技蓝）**：默认主题，适合技术干货、架构复盘与开发手记，代码块带 Mac 三色圆点，表格带斑马纹；
- **vintage-news（复古报刊）**：米黄色纸质底色，搭配粗衬线字体、古典双细线标题和学术三线表，适合人文深度长文与书摘；
- **terminal-geek（极客终端）**：黑底绿字，等宽命令行风格，适合 Linux 运维、开源发布与黑客范笔记；
- **warm-memo（温暖便签）**：暖杏底色配胶囊色块和便签卡片，适合生活随笔与治愈手作；
- **acid-bold（先锋野兽派）**：粗黑边框配黑色硬投影，视觉冲击强烈，适合潮流观点与青年专栏。

![MD2WX 主题选择与设置调优面板](assets/md2wx-settings-panel.png)

如果你希望对细节精雕细琢，还可以展开右上角的排版设置面板，针对基准字号（15px ~ 17px）、黄金行高（1.75 ~ 1.95）、字间距以及段落首行缩进进行微调。

### 第三步：一键复制并粘贴进公众号后台
确认右侧视口的阅读节奏与版面舒适度后，点击右上角的 **「复制富文本」** 按钮。

打开微信公众平台（mp.weixin.qq.com）的新建图文页面，在正文中按下键盘的 **Cmd + V（Windows 用户按 Ctrl + V）**，整篇文章的标题样式、字号行距、代码块与引用框就会完好无损地贴入微信编辑器中。

## 03. 专为微信生态打磨的核心细节

除了基础的内联样式转换，MD2WX Web Studio 还内置了几处专门针对微信生态排版痛点的细节设计：

### 1. 外链自动转文末脚注
微信正文为了平台安全，不允许直接点击跳转任意外部超链接。如果你的文章中有 `[开源仓库](https://github.com/...)` 这样的链接，读者在手机上点击是完全没有反应的。

MD2WX 会在解析时自动将普通超链接转译为带上标的引用标记（如 `开源仓库 [1]`），并在文章的最末尾自动生成整齐划一的「参考链接」脚注卡片：

![外链自动转文末脚注与纯内联代码块高亮](assets/md2wx-footnotes-card.png)

读者既能在正文顺畅阅读上下文，又能在文末方便地复制完整出处链接。

### 2. 拒绝代码块被微信压扁与错位
微信编辑器在导入 HTML 时，会对 `<pre>` 和 `<code>` 标签做严苛的过滤净化，常规外部 CSS 高亮经常会被清空，或者因为缺少 `white-space` 保留而在手机端挤成一团。

MD2WX 内部实现了自包含的换行与空格保留机制，每一行代码直接以内联 `<span>` 注入高亮颜色，并在横向滚动容器上固定绘制深色底色，即使是在窄屏手机上横向滑动长行代码，也绝不会出现文字溢出或漏底的情况。

### 3. iPhone 16 Pro 仿真视口与全宽视图自由切换
在电脑宽屏上看起来松散好看的段落，到了手机小屏幕上经常变成大段密不透风的文字墙。

MD2WX 默认开启了真实的 iPhone 16 Pro 仿真视口（宽度精准对齐 393px 移动视口与安全边距），还原微信客户端真机阅读体验。若需纵览全局长图，点击工具栏即可一键切换为桌面全宽视图。

### 4. 双栏精准联动滚动
文章内容很长时，很多工具在左边滚了几屏，右边预览依然停在开头。MD2WX 实现了平滑的双栏联动算法，滚动左侧源码时，右侧仿真视口会按比例精准平移，无需两边反复手动拖拽找位置。

## 04. 为什么坚持完全免费与纯前端

市面上绝大多数微信排版工具采用的都是「后端渲染 + 云端账户 + 增值付费」的商业模式，服务器需要维护庞大的模板数据库，运营成本高昂，因而必然会设置收费门槛。

而 MD2WX 采用了彻底的**纯前端（Vanilla JS + CSS）架构**：
- 它不需要昂贵的后端服务器集群支撑，所有计算都在你的本地浏览器完成；
- 它不依赖第三方大厂的重型框架，页面加载体积极小，响应迅速；
- 因为没有服务器带宽包袱，所以它能够做到**永远免费、代码开源、零追踪、零广告**。
