# v1.8.1: 示例、工具栏与默认主题

这一版把默认体验重新收拾了一遍：打开工作台看到的第一篇文章，能直接当语法手册用；编辑器上方的按钮补齐了常用写法；默认主题换成更醒目的先锋野兽派。

## 默认示例覆盖全部语法

Web 工作台与 CLI 现在共用仓库根目录的 `sample_article.md`，示例只有一份，不会再出现两边内容对不上的情况。

示例按段落覆盖了当前支持的写法：

- Frontmatter 元信息、ATX 与 Setext 标题、H1 - H6；
- 粗体、斜体、粗斜体、删除线、荧光高亮、行内代码、下划线、上下标；
- 转义字符、行尾双空格与反斜杠硬换行；
- 多级引用、无序/有序/任务列表、嵌套列表；
- 表格对齐、围栏代码块、波浪线围栏、四空格缩进代码；
- 行内公式、块级公式、Mermaid 流程图；
- 独立图片、图注、引用式图片、Obsidian `![[...]]` 图片；
- 行内链接、引用式链接、裸链接、邮箱、文本脚注与参考链接区。

## 编辑器工具栏补齐

新增 H3、删除线、荧光高亮、行内代码、有序列表、任务清单、数学公式、Mermaid 八个按钮。按钮变多后工具栏支持横向滚动，窄屏下不会挤压编辑区。

## 默认主题改为 acid-bold

CLI、Web 工作台与封面渲染的默认主题统一为 `acid-bold`（先锋野兽派）。封面预设与未知主题的兜底也同步调整。

已有浏览器如果存过主题选择，会继续沿用 localStorage 里的旧主题；清掉站点数据或重新选择即可切到新默认值。

## 其他修复

- 预览顶部封面卡片改为从完整原文提取元数据，作者字段现在能正确读取 Frontmatter 的 `author`，不再固定显示示例作者。
- 顺手更新 README 主题表与教程中的默认主题说明。
