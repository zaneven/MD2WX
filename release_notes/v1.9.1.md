# v1.9.1: 落地页主题预览联动与窄屏溢出修复

v1.9.0 之后的一轮落地页修复。官网演示区的主题切换从"只换三条颜色"改成整块预览骨架联动，同时把窄屏下撑出横向滚动条的问题处理掉。

## 落地页演示区

- 右侧微信模拟视窗整体由 `data-preview-theme` 驱动：终端黑、复古报刊、先锋野兽派各自还原自己的深色底、衬线双线、粗黑硬投影与代码配色，切换主题不再只有页眉一条线变色。
- 主题按钮联动主题色与 `aria-pressed` 状态，预览副标题同步显示当前主题名，方便对照。
- 主题缩略图改为预载完成后再替换，并加点击序号兜底，连点多个主题时不会被慢图覆盖成错位画面；图片加载失败也会恢复亮度，不会一直灰着。
- 750–900 宽度区间收起源码栏，避免左右两栏互相挤压。

## 移动端适配

- 窄屏隐藏导航里的 Star 按钮并收窄容器内边距，修复 360–414 宽度下导航撑出横向滚动条的问题。

## 文档

- Studio 的版本速递弹窗同步到 v1.9.0 的发稿体检、发布门禁与大纲导航。
- `AGENTS.md` 发布流程新增第 4 步：每次发版必须同步更新记录弹窗，不能只换版本号。

## 验证

- `python3 -m pytest` 200 项通过，Web 端 `npm test` 与 `npm run build` 无报错。
- 在 1920 / 1440 / 1280 / 900 / 768 / 414 / 360 宽度下检查落地页，均无横向滚动条。
